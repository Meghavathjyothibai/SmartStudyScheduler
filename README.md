# Smart Study Scheduler

Smart Study Scheduler is a web-based productivity tool designed to help students create personalized study plans based on subject priority, required study hours, and deadlines. It offers a professional and interactive experience with a secure login and automated schedule generation.

---

##  Features:

-  Secure login using a secret password  
-  Add subjects with priority, study hours, and deadlines  
-  Generate intelligent and sorted study plans  
-  Mark subjects as completed  
-  Clear completed or all subjects with one click  
-  Clean and responsive design for usability

---

##  Technologies Used:

- **HTML5** – for the structure and layout  
- **CSS3** – for styling and layout responsiveness  
- **JavaScript (ES6)** – for app logic and interactivity  
- **DOM Manipulation** – to dynamically render content based on user input
